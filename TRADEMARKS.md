# Trademark Policy

The VEYRA code is open source. The **VEYRA name, logo and visual identity are not** covered by the code licences.

You may:

- Fork, modify and redistribute the code under its licences.
- Say your project is "based on VEYRA" or "a fork of VEYRA".

You may not, without written permission:

- Call your build "VEYRA", or use the VEYRA logo, in a way that suggests it is an official VEYRA release.
- Distribute builds signed with keys that claim to be VEYRA's, or that point users to VEYRA's update channels while shipping modified code.

Forks must use their own name, their own signing keys and their own Microsoft Entra application (client ID).

Official VEYRA builds are the ones published in this repository's GitHub Releases with a manifest signed by the project's keys.

A trademark search for the VEYRA name has not been done yet (tracked as owner action H8).
